# Frontend (Expo)

React Native Expo app for the StudyStreaks MVP.

## Screens

- `Home`: lists groups, creates groups, joins groups
- `Profile`: email/password auth with Supabase

## Environment

Copy values from `.env.example` into `.env`.

- `EXPO_PUBLIC_SUPABASE_URL`
- `EXPO_PUBLIC_SUPABASE_PUBLISHABLE_DEFAULT_KEY`
- `EXPO_PUBLIC_API_BASE_URL`

## Commands

```bash
npm install
npm start
npm run lint
```
